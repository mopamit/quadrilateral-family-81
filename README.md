# משפחת המרובעים על סריג — פריזמה

יישומון חקר אינטראקטיבי לכיתה ז׳.

## הפעלה
פתחו את `index.html` בדפדפן, או העלו את כל התיקייה ל-GitHub Pages.

## מה התלמיד עושה
- גורר את הקודקודים A–D על נקודות הסריג.
- רואה בזמן אמת אילו תכונות מתקיימות.
- מנסה לזהות את המרובע לפני לחיצה על "גלה את המרובע".
- פותר משימות חקר קצרות.

## משפחות שנבדקות
מקבילית, מלבן, מעוין, ריבוע, וכן מרובע כללי.
